Prompts & Tools

Designing planner prompts, capability cards, and tool schemas that models can actually follow.

  • Writing capability cards for planners2 minWrite capability cards (tool descriptions) that LLM planners follow reliably: clear identity, when and when not to use, parameter docs, side-effect class and examples.
  • Planner policy without prompt soup2 minWrite planner policy for AI agents without prompt soup: one home per rule, positive instructions, clear priorities, short examples and tests for each rule that matters.
  • Lookups: enrich, don't auto-select2 minTeach AI agents to look up entity ids instead of guessing: lookup tools, a lookup trace in state, replanning with candidates and asking the user when results are ambiguous.
  • Bilingual compose for developers2 minCompose assistant replies in two languages such as English and Arabic: schema fields for each locale, consistent terminology, right-to-left rendering and locale-aware testing.
