Designing planner prompts, capability cards, and tool schemas that models can actually follow.

  • 01Writing capability cards for planners
    Write capability cards (tool descriptions) that LLM planners follow reliably: clear identity, when and when not to use, parameter docs, side-effect class and examples.
  • 02Planner policy without prompt soup
    Write planner policy for AI agents without prompt soup: one home per rule, positive instructions, clear priorities, short examples and tests for each rule that matters.
  • 03Lookups: enrich, don't auto-select
    Teach AI agents to look up entity ids instead of guessing: lookup tools, a lookup trace in state, replanning with candidates and asking the user when results are ambiguous.
  • 04Bilingual compose for developers
    Compose assistant replies in two languages such as English and Arabic: schema fields for each locale, consistent terminology, right-to-left rendering and locale-aware testing.
