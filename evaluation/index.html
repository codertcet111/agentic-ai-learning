Eval & Observability

Measuring planner quality, tool accuracy, and latency budgets.

  • Golden JSON cases2 minHow to structure golden JSON test cases for an AI agent: one file per scenario, tags, fixtures, expectations that can be checked mechanically and schema validation in CI.
  • LLM-as-judge—with guardrails2 minUse LLM-as-judge evaluation for qualities like helpfulness and groundedness with clear rubrics and calibration, while keeping safety and tool correctness on deterministic checks.
  • Trace compare across releases2 minCompare agent traces across releases: run golden cases, export node sequences, LLM call counts, tokens and latency, and diff them against an approved baseline.
  • Observability stack choices2 minChoose an observability stack for AI applications: structured logs, distributed tracing and APM, LLM-specific observability like Langfuse, and error tracking, tied together by ids.
  • Langfuse scores from CI2 minAttach evaluation scores to Langfuse traces from CI and production checks, tag releases, and use score trends to spot regressions in routing, tool use, latency and cost.
