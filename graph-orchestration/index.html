Graph & Orchestration

LangGraph patterns, routing functions, and multi-agent handoffs—explained for builders.

  • Conditional routing without side effects2 minWrite LangGraph routing functions as pure selectors that read state and return the next node, so graph diagrams stay truthful and every edge is unit-testable.
  • Checkpointing and recovery2 minHow LangGraph checkpoints work, how to persist them in MongoDB, how to resume after crashes or pauses, and how to keep checkpoint size and retention under control.
  • Multi-agent delegation2 minStructure multi-agent systems with a registry of agent cards, capability subsets per agent, a router that hands off ownership and one shared turn pipeline.
  • Human-in-the-loop pauses2 minDesign human-in-the-loop pauses for approvals and forms with durable pending state, expiry, fingerprints against stale UI and clear transition messages.
  • Debugging graph bugs with traces2 minA practical method for debugging LangGraph agent bugs with traces: reproduce, find the request id, walk the span tree and diff node sequences against a known-good run.
  • Keeping GraphState small2 minKeep LangGraph state small by storing large tool results by reference, summarizing for the planner and measuring checkpoint size, so resumes stay fast and cheap.
