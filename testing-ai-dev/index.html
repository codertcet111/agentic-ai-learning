Testing as an AI Dev

pytest, fakes, and graph specs without flaking on real models.

pytest, fakes, and graph specs without flaking on real models.

  • 01Graph tests as executable spec
    Treat agent graph tests as an executable specification: routing, pending form resume, supersede and error paths described as fast pytest cases with a stub LLM and fakes.
  • 02Fakes for Mongo and Redis
    Use in-memory fakes for MongoDB repositories and Redis in agent backend tests: repository interfaces, behaviour that matches the real store, and integration tests behind a marker.
  • 03Running golden evals locally
    Run golden evaluation cases locally and in CI: fast stub-LLM runs for plumbing, nightly live-model runs for behaviour, tag selection and readable diff reports.
  • 04Testing observability hooks
    Test observability code in AI agents: assert span names and attributes with in-memory exporters, verify masking removes personal data, and check no secrets reach traces.
