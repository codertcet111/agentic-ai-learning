Mongo for AI

Schema patterns for chat, tools, eval artifacts, and knowledge metadata.

  • Chat message schema2 minA MongoDB schema for AI chat messages: append-only documents, sequence ordering, structured content blocks, tool-call links and the indexes that make it fast.
  • Interaction and form schema2 minA MongoDB schema for pending forms, confirmations and choices in an agent workflow, with JSON Schema validation, revisions, fingerprints, expiry and status indexes.
  • Usage counters and quotas1 minTrack LLM tokens, model costs and tool invocations per tenant and day in MongoDB with atomic upserts, for dashboards and quotas, plus how to reconcile against provider billing.
  • Failure records for support2 minPersist sanitized failure records for agent turns in MongoDB with stable error classes, correlation ids and safe context, so support can resolve issues without raw logs.
  • Vector metadata alongside Mongo2 minKeep chunk metadata such as source, ACL scope, versions and embedding model in MongoDB alongside a vector store, so RAG retrieval is filterable, auditable and re-indexable.
  • Turn ledger for developers2 minA developer's guide to the turn ledger: states, transitions, idempotent replays, stuck-turn sweeps and the queries to run when a chat turn hangs or duplicates.
  • Idempotency keys in chat APIs2 minIdempotency patterns for chat and agent APIs: client keys on messages, partial unique indexes, replaying stored results and operation ids that protect upstream writes.
