Schema patterns for chat, tools, eval artifacts, and knowledge metadata.

  • 01Chat message schema
    A MongoDB schema for AI chat messages: append-only documents, sequence ordering, structured content blocks, tool-call links and the indexes that make it fast.
  • 02Interaction and form schema
    A MongoDB schema for pending forms, confirmations and choices in an agent workflow, with JSON Schema validation, revisions, fingerprints, expiry and status indexes.
  • 03Usage counters and quotas
    Track LLM tokens, model costs and tool invocations per tenant and day in MongoDB with atomic upserts, for dashboards and quotas, plus how to reconcile against provider billing.
  • 04Failure records for support
    Persist sanitized failure records for agent turns in MongoDB with stable error classes, correlation ids and safe context, so support can resolve issues without raw logs.
  • 05Vector metadata alongside Mongo
    Keep chunk metadata such as source, ACL scope, versions and embedding model in MongoDB alongside a vector store, so RAG retrieval is filterable, auditable and re-indexable.
  • 06Turn ledger for developers
    A developer's guide to the turn ledger: states, transitions, idempotent replays, stuck-turn sweeps and the queries to run when a chat turn hangs or duplicates.
  • 07Idempotency keys in chat APIs
    Idempotency patterns for chat and agent APIs: client keys on messages, partial unique indexes, replaying stored results and operation ids that protect upstream writes.
