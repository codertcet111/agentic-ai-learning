Langfuse Lab

Developer walkthrough of LLM traces: failures, span trees, token cost per node, turn checks, and privacy-safe export.

Developer walkthrough of LLM traces: failures, span trees, token cost per node, turn checks, and privacy-safe export.

  • 01Langfuse workflow for AI developers
    A day-to-day Langfuse workflow for AI developers: one trace per chat turn, consistent observation names, safe capture modes, release tags and linking traces to logs.
  • 02Traces list: spot failures and slow turns
    Use the Langfuse traces list to find failed and slow agent turns after a deploy: filter by environment and time, sort by latency and cost, and search by conversation or request id.
  • 03Span tree: cost and time per graph node
    Read the Langfuse span tree to see time and cost per graph node, spot planner loops and slow tool calls, and explain why a particular chat turn was expensive.
  • 04Trace detail: IO, tokens, and model metadata
    Inspect a Langfuse generation in detail: structured input and output, token breakdown including cached tokens, cost, model metadata and the scores attached to the turn.
  • 05Turn checks: automated budgets on every trace
    Run automated turn checks when each agent trace completes: limits on LLM calls, wall-clock time, slow generations, cost and reply size, recorded as Langfuse scores.
  • 06Masking residuals, failures, and Rollbar alerts
    Mask personal data before exporting LLM traces, alert on residual PII without logging the values, and record clear failure reasons on root traces for faster debugging.
  • 07Local Langfuse setup checklist
    A checklist for setting up Langfuse tracing locally for an agent backend: environment variables, region, capture mode, first trace, and common reasons traces do not appear.
