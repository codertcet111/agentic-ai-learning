LLM Engineering

Day-to-day model integration: LiteLLM, structured outputs, stubs, and routing—from an implementer's chair.

  • LiteLLM as a single gateway2 minRoute every model call through one gateway such as LiteLLM: model aliases in config, central timeouts and retries, fallbacks, token accounting and provider portability.
  • Structured outputs in production2 minGet reliable structured outputs from LLMs in production: Pydantic schemas, provider-native JSON schema modes, semantic validation, a single repair attempt and safe failure.
  • LLM_STUB and deterministic CI2 minUse a stub LLM (LLM_STUB) to run agent graph tests and golden cases deterministically in CI without API keys, and keep stub fixtures in sync with schemas.
  • Token window management2 minManage the LLM context window in chat agents: token budgets per section, recent-turn windows, summaries of older turns, compact tool results and measuring the effect in traces.
  • When to use small vs large models2 minDecide when to use small versus large language models in an agent: route by purpose, measure with traces, escalate on low confidence and evaluate each tier on its own tasks.
  • Streaming responses to the client2 minStream LLM responses to chat clients safely: admit the turn first, stream only the compose step, handle client aborts, and reconcile the turn ledger so retries stay correct.
